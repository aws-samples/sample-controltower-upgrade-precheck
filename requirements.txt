# The tool uses the AWS SDK for Python (boto3). Control Tower baseline APIs
# (ListEnabledBaselines / GetLandingZone drift status) require a reasonably
# recent botocore, so a modern boto3 is pinned as the floor.
#
# This is a floor and not an exact pin on purpose. The tool's preflight checks whether the
# installed SDK exposes those APIs and tells you to run `pip install -U 'boto3>=1.34'` when
# it does not, so freezing the runtime to one version would work against that, and would
# leave you on an ageing SDK. If you need a byte-identical environment, capture the resolved
# closure yourself with `pip freeze > requirements.lock` after installing from this file.
boto3>=1.34.0
